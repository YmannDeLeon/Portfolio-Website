# LEON.DEV Portfolio

A responsive, dark navy personal developer portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
Open `index.html` in your browser. No build step or dependencies required.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your public contact email.
2. Review the About and Skills copy so it accurately reflects your current experience.
3. Replace planned project concepts with real projects as you build them.
4. Add your GitHub and Fiverr links when ready.

## Deploy to Vercel
1. Create a GitHub repository and upload the contents of this folder.
2. Sign in to Vercel with GitHub and import the repository.
3. Keep the framework preset as **Other** and leave the build command and output directory empty/default for a static site.
4. Deploy.

This is a personal portfolio starter. Check the hosting provider's current plan terms before using it for commercial/client work.
